GALLERIES: VIDEO FILES NEEDED
=============================

Drop web-optimized clips here, in these subfolders, using these exact names.
Every clip needs BOTH a .webm and a .mp4 (Safari and iOS don't reliably play
WebM, so the pages list .webm first with an .mp4 fallback). See
GALLERIES_BUILD_NOTES.md at the repo root for the full explanation and the
source-clip mapping.
